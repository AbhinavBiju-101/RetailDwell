Create or revoke keys

Keep the key out of your command history. Set it once in the shell where the agent runs:

export DWELL_API_KEY=dtm_YOUR_KEY

2. Calibrate the camera (once per camera)

Pick 4 to 8 spots on the floor you can measure with a tape, such as tile corners or marks you tape down. Spread them across the area the camera sees. Measure each one in metres from the bottom-left corner of the floor plan (this store is {{ '%g'|format(store.width_m) }} m wide and {{ '%g'|format(store.height_m) }} m deep).

pip install -r requirements-video.txt

python -m agent snapshot --source rtsp://CAMERA_ADDRESS/stream --out frame.png
python -m agent click --image frame.png --width {{ '%g'|format(store.width_m) }} --height {{ '%g'|format(store.height_m) }} --out calib.json
python -m agent check --calib calib.json --image frame.png

snapshot saves one frame. click opens it so you can click each spot and type its position. check reports the error in metres and draws a 1 m grid on the frame. Aim for under 0.15 m, and delete frame.png and the overlay afterwards because they may show people.

Staff rooms and other areas to leave out

Add rectangles to calib.json and the agent never records anything inside them. Points outside the floor size are dropped automatically.

"floor_size": [{{ '%g'|format(store.width_m) }}, {{ '%g'|format(store.height_m) }}],
"exclude": [[0, 0, 2, 3]]

3. Run it on layout {{ layout.key }}

python -m agent run \
  --source rtsp://CAMERA_ADDRESS/stream \
  --calib calib.json \
  --layout {{ layout.key }} \
  --api {{ host }} \
  --recording "Live"

To try it on a recorded clip first, use --source clip.mp4 and add --csv tracks.csv.gz instead of --api, then upload the file in Settings.

If the app is unreachable the agent keeps points in a spool folder and sends them on the next start. A wrong key or layout stops the agent with a message that says what to fix.

Before you rely on it

The agent has been tested on synthetic video only. Run it on a real clip and compare a few zones against what you see on the floor before trusting the numbers.
